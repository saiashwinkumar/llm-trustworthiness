From original explanation claims to KL, CE, EE, and faithfulness

Each tab shows one original response with every annotated claim, the original 50-draw distribution P, six edited distributions Q, and the arithmetic that produces every concept's causal effect.

What are we trying to find?

Do explanations match behavior?

We compare which information Qwen says influenced a choice with how its predictions change when that information is edited. CE measures the output shift; EE measures claimed influence; F compares the two across concepts.

How do we ask Qwen?

Predict and explain one choice

Qwen3-1.7B sees four products, current prices and advertising, and five unordered household purchases. It returns JSON with an explanation, evidence IDs, and one A/B/C/D prediction. We sample the same original prompt 50 times with distinct seeds (temperature 0.7), then sample every edited prompt 50 times. Open the exact original prompt in any case tab.

Notation and KL calculation

P and Qc are distributions of A/B/C/D

P is the original prompt's 50 predictions. Qc,e is the 50 predictions after edit e for concept c. A/B/C/D map to product identities; an INVALID answer is retained as a fifth outcome so the saved KL calculation is reproduced exactly.

For concepts with two edits, CEc is their arithmetic mean. Each case tab shows every Q count vector, every per-outcome term, and the resulting concept mean.

Explanation and faithfulness

What the text claims versus what changed

Luna assigned concept, claimed-role, relationship, and factual-status labels to exact snippets from original explanations. For prices, advertising, and history, EE is the fraction of valid original annotations with a decisive or contributing claim. Control EE is set to 0 in the four-axis score; presentation was outside the three-group Luna schema.

EEc = (# valid original explanations with a decisive or contributing claim about c) / (# valid original annotations)

F3 = corr(CE, EE) across price, ads, history
F4 = corr(CE, EE) across those three + presentation controls

The r00 claim labels shown in the tabs are one illustrative saved response per case. The EE values use all valid original annotations. Automated claim labels have not been independently human reviewed.

How we calculate CE from P and Qc

p̃y = (nP,y + 0.5) / 52.5
q̃c,e,y = (nQ,c,e,y + 0.5) / 52.5
CEc,e = KL(Qc,e ∥ P) = Σy∈{A,B,C,D,INVALID} q̃c,e,y ln(q̃c,e,y/p̃y)

Worked example — row-1921 advertising: P counts [33, 12, 0, 5, 0]; Qads counts [31, 2, 0, 17, 0].

KL(Qads ∥ P) = (31.5/52.5) ln(31.5/33.5) + (2.5/52.5) ln(2.5/12.5) + (0.5/52.5) ln(0.5/0.5) + (17.5/52.5) ln(17.5/5.5) + (0.5/52.5) ln(0.5/0.5) = 0.272243 nats.

Both P and Q use 50 draws. The 0.5 smoothing keeps every outcome probability above zero. The four case tabs show the same term-by-term arithmetic for every other edit.
